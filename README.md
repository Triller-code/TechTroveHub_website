# NovaCart - E-Commerce Shopping Website

NovaCart is a modern, fully responsive e-commerce shopping website. It features an interactive product display, a shopping cart system, smooth animations.


---

## Features

Animated Product Cards with hover effects

Carousel Page showcasing featured products

Shopping Cart System to manage selected items

Related Products Section for personalized recommendations

About Us & Testimonials with smooth scroll animations

Fully Responsive Design for desktop and mobile



---

### Installation

1. Clone the Repository

git clone https://github.com/yourusername/novacart.git  
cd novacart

2. Install Dependencies

npm install

3. Start the Development Server

npm run dev

4. Open the Website

Visit http://localhost:3000 in your browser.


---

## Project Structure

NovaCart's frontend consists of the following main components:

aboutus.tsx - About Us section

cardcarousel.jsx - Product showcase carousel

cards.jsx - Product cards with animations

footer.jsx - Website footer

home.tsx - Homepage layout

testimonials.jsx - Customer testimonials
